# Wrath

Native iOS 27 media downloader with yt-dlp, FFmpeg, and Liquid Glass.

Download the unsigned IPA from [v0.1](https://github.com/DjangoCustard225/Wrath/releases/tag/v0.1) and sign it with your sideloading tool.

Build on macOS with Xcode 27 and Python 3: `python3 Scripts/Build.py`.
